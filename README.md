# rabotavvkusno-qa-tracker
Трекер дефектов сайта rabotavvkusno.ru. Содержит документированные баги с полным набором артефактов: шаги воспроизведения, скриншоты Network/Console, ожидаемый и фактический результат, метки Severity/Priority. Цель — обеспечить прозрачность процесса исправления дефектов и минимизировать уточнения между QA и разработкой.
